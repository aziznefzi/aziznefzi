## About Me

I'm **Aziz Nefzi**, a self-taught software engineer and the founder of **[Almostaqel aQademy | أكاديمية المستقل](https://www.almostaqelaqademy.com/)**.

My programming journey began with learning the fundamentals on my own. I am especially interested in understanding how software works beneath the surface, with a particular inclination toward **C, C++ and low-level programming**.

I value understanding fundamentals over relying blindly on abstractions or libraries. I aim to make thoughtful engineering decisions with a focus on **performance, security, maintainability, and simplicity**.

I am also inspired by the work and programming philosophy of **[Casey Muratori](https://caseymuratori.com/)**, particularly the emphasis on understanding systems and building software deliberately.

## Engineering Principles

- **Understand the fundamentals:** learn what happens beneath high-level abstractions.
- **Performance matters:** consider efficiency and resource use as part of good engineering.
- **Security by design:** treat security as an essential part of software development, not an afterthought.
- **Build with purpose:** choose tools and dependencies because they solve a real problem.
